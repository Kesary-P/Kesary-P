## Objectif

Construire une application qui permet de gérer des données persistantes avec les quatre opérations fondamentales d’un CRUD :

- **Create** : ajouter un enregistrement ;
- **Read** : consulter une liste ou une fiche ;
- **Update** : modifier les informations existantes ;
- **Delete** : supprimer un enregistrement avec confirmation.

## Architecture prévue

L’interface HTML/CSS/JavaScript communiquera avec une logique serveur chargée de valider les données et d’interroger une base de données. Le projet séparera clairement l’affichage, les règles métier et l’accès aux données.
