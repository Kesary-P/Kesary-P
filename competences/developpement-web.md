# Développement web

[← Retour au profil](../README.md)

Cette rubrique présente ma progression à travers deux types de réalisations complémentaires. Chaque projet documente les choix techniques, ce que j’ai développé et les compétences que je peux réutiliser dans un contexte professionnel.

## 1. Site statique responsive

### [Échappées — carnet de voyage interactif](site-statique.md)

Une interface composée de plusieurs pages, développée à partir de maquettes desktop et mobile.

**Compétences démontrées :**

- structuration sémantique avec HTML5 ;
- mise en page responsive avec CSS3 et LESS ;
- interactions côté navigateur avec JavaScript ;
- accessibilité, navigation et adaptation mobile ;
- versionnement Git et publication continue avec GitHub Actions ;
- documentation technique et présentation des maquettes.

[Voir le site](https://kesary-p.github.io/echappees-voyage/) · [Voir le dépôt](https://github.com/Kesary-P/echappees-voyage)

### Aperçu du résultat

| Version desktop | Version mobile |
| --- | --- |
| ![Page d’accueil Échappées sur desktop](https://raw.githubusercontent.com/Kesary-P/echappees-voyage/main/docs/maquettes/accueil-desktop.png) | ![Page d’accueil Échappées sur mobile](https://raw.githubusercontent.com/Kesary-P/echappees-voyage/main/docs/maquettes/accueil-mobile.png) |

Ces deux vues montrent comment une même structure s’adapte à la largeur disponible : navigation complète sur desktop, menu compact sur mobile, contenus réorganisés et dimensions ajustées pour conserver une lecture confortable.

## 2. Application dynamique CRUD et base de données

### [Projet d’application dynamique — en construction](application-dynamique.md)

Cette deuxième étape montrera ma capacité à dépasser l’interface statique pour gérer des données persistantes : création, consultation, modification et suppression d’enregistrements.

La documentation sera complétée au fur et à mesure avec le schéma de données, les routes, les contrôles de saisie, les tests et les choix de sécurité.
